# Citrea Voting Smart Contract

This repository contains a secure, decentralized voting smart contract built using **Solidity**. It was developed as part of a hands-on technical workshop during the **Citrea India Tour**.

## Overview
The goal of this project was to understand the fundamentals of Web3 development and smart contract deployment on Citrea,an EVM-compatible Zero-Knowledge (ZK) rollup secured by Bitcoin.

## Features Implemented
 **Voter Registration:** Logic to authorize unique Ethereum/Citrea wallet addresses to vote.
 **Tamper-Proof Voting:** Secure function allowing registered users to cast a single ballot.
 **Real-Time Tallying:** Automatic, decentralized calculation of voting results directly on the blockchain.
 **Immutability:** Once deployed, the rules of the vote cannot be altered by anyone.

## Tech Stack
 **Language:** Solidity
 **Ecosystem:** Citrea (ZK-Rollup Layer 2)
